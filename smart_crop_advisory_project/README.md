
# Smart Crop Advisory Project

## Technologies Used
Frontend:
- HTML
- CSS
- JavaScript

Backend:
- Python Flask

## Features
- Crop recommendation
- Soil analysis
- Temperature checking
- Rainfall checking
- Simple advisory system

## Run Backend
cd backend

pip install -r requirements.txt

python app.py

## Run Frontend
Open frontend/index.html in browser

## API URL
http://127.0.0.1:5000/predict
